## Rehearsal checklist

- [ ] Docker `mysql`, `app`, `nginx` aktif; `/api/health` HTTP 200.
- [ ] `/api/dashboard` tanpa login HTTP 401; TV login tetap berfungsi.
- [ ] Empat slide berputar, tidak ada placeholder `Data lama` tidak sengaja; `?lite=1` berfungsi.
- [ ] Delapan proyek dummy tampil dan tidak ada data klien asli.
- [ ] Akun demo coordinator, engineer dan viewer login normal; password tidak ditampilkan.
- [ ] Tugas dan verifikasi dummy ada untuk diperlihatkan. Jika kosong, cukup jelaskan UI tanpa mengimpor ulang seeder.
- [ ] Tiga dokumen dummy terbuka dan file PDF tidak bisa diunduh tanpa hak.
- [ ] Halaman Riwayat terbuka untuk management dan tertutup bagi engineer/viewer.
- [ ] Halaman Akun terbuka hanya untuk admin/coordinator; tidak perlu reset nyata saat presentasi.
- [ ] Backup SQL terkini tersedia; file PDF volume `ftu_uploads` dipertahankan.
- [ ] Browser diperbarui dan cache aset terbaru; resolusi layar, speaker, kabel/TV diuji.
- [ ] Tidak ada `git commit` atau `php artisan migrate` saat presentasi.
