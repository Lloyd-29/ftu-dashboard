# FTU Dashboard

Aplikasi dashboard proyek internal PT Filosofi Teknik Utama.

## Lingkup versi 1

- Dashboard TV dengan empat halaman yang berganti otomatis.
- Pengelolaan progres proyek, engineer, milestone, catatan klien, dan peringatan.
- Hak akses admin, editor, dan viewer.
- Tidak menyimpan informasi keuangan.

## Teknologi

- Backend: Laravel REST API dan MySQL 8.
- Frontend: React, TypeScript, dan Vite.
- Infrastruktur: Docker Compose dan Nginx.

## Lingkungan

- Development: Windows 10 Pro 22H2.
- Production: Windows 11 (spesifikasi menyusul).
